ST2504 Applied Cryptography Assignment 2

Project: Secure Client-Server File Transfer System

How to run:
1. Install dependencies: pip install -r requirements.txt
2. Generate RSA-2048 keys: python source_files/generate_keys.py
3. Start server: python source_files/server.py
4. Run client: python source_files/client.py sample_files/sample_message.txt
